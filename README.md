# 🧮 BMI Calculator - Android App

A clean, modern, and user-friendly **BMI (Body Mass Index) Calculator** Android application built using Java and XML. This app helps users easily calculate their BMI and understand their health status based on their height and weight inputs.

---

## ✨ Features

- 📏 **Dual Unit Support:** Calculate BMI using metric units (Height in cm/meters, Weight in kg).
- ⚡ **Real-time Results:** Fast and accurate BMI calculation.
- 🎨 **Health Category Indicator:** Instant feedback on health status:
  - Underweight (< 18.5)
  - Normal weight (18.5 – 24.9)
  - Overweight (25 – 29.9)
  - Obese (30 or greater)
- 📱 **Clean UI/UX:** Minimalist, intuitive, and easy-to-use interface.

---

## 🛠️ Tech Stack & Tools

- **Language:** Java
- **UI Design:** XML (Layouts, Material Design Components)
- **IDE:** Android Studio
- **Version Control:** Git & GitHub
- **Min SDK:** Compatible with Android 5.0 (API Level 21) and above
